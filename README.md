DraggableView
=============

> **Archived, no longer maintained (September 2026).**
> This 2014 Objective-C component targets iOS 5/6, does not build with current Xcode, and relies on
> APIs deprecated since iOS 13. For swipeable cards today, use SwiftUI's `DragGesture` with
> `.offset` and `.rotationEffect`, or a maintained library such as
> [Koloda](https://github.com/Yalantis/Koloda) or [Shuffle](https://github.com/mac-gallagher/Shuffle).
> Note that the `DraggableView` name on CocoaPods trunk belongs to an unrelated pod.

A Tinder-like draggable view that over a certain threshold animates out of the screen.
